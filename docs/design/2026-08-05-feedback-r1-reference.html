Entry & Create

Muted 0–0 defaults, centered common-score shortcuts, centered stacked score boxes, and the local-friendly create deadline.

01B
Scoreline default 0-0 · alternative

Add a common-score row

The same 0–0 starting point stays honest, while likely outcomes sit one tap away beneath each fixture.

The shortcut helps most picks move from “default” to “chosen” without opening the steppers.

02B
Score row alignment · option B

Stack each club above its score

Home and away each own a clean vertical stack. The separator disappears into the two-column layout, while both steppers share one horizontal baseline.

Club names can grow without pushing a score control up or down.

03
Create league datetime · owner choice

Make the first deadline human

Keep the useful context around the competition picker, but turn the first deadline into a line someone can scan and repeat back.

The friendly line gives the date, local time, timezone, and a short sense of urgency together.

Format rule: weekday, day month, local 12h time, timezone abbreviation when needed, relative parenthetical under 7 days.
Global build notes

Rules that travel with every frame

  1. Datetime rule: the friendly format applies EVERYWHERE a date/time is displayed in the app (deadlines, kickoffs, settle times, activity log), and times render in the USER'S LOCAL timezone (from the device), not hardcoded IST — show the tz abbreviation where ambiguity is possible.
  2. Table formatting standard: League screen Option B, with the sticky-column fix, applies to ALL tables app-wide.
  3. Entry status copy: the eight-state table is canonical — “entry submitted”, never “entry started”.
  4. Tab switches: everywhere, use client-side content-pane swaps, never full page reloads.
  5. Lists and tables: no collapsed/summary rows anywhere — every list and table is complete and scrollable.
  6. Home navigation: the Bracket tab is removed from home.
